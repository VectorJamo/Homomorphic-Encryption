# Homormorphic Encryption Library
Homomorphic Encryption library currently under development. Meant to be used for AI/ML computations.
Author: Suraj Neupane

## Installation
Clone the repository and start a new jupyter notebook project from the main directory.


Libraries required: **TenSEAL**

Can be installed using the following command(s) for your specific platform:

**1. Windows**
```bash
pip install tenseal
````

**2. Linux/MacOS**
A. Create a virtual environment and activate it.
```bash
python3 -m venv tenseal-env
source tenseal-env/bin/activate
````

B. Install `tenseal`
````bash
pip install tenseal
````
